## Visão Geral

Este portfólio foi concebido para transmitir a maturidade de um desenvolvedor focado em **sistemas internos, APIs de alto desempenho, automações operacionais (RPA) e bancos de dados relacionais**.

Diferente de portfólios genéricos repletos de porcentagens arbitrárias, este projeto é centrado em **storytelling visual, arquitetura em camadas e resolução de problemas reais de negócios**.

## Como Executar Localmente

### 1. Instalar dependências (caso ainda não estejam instaladas)
```bash
npm install
```

### 2. Rodar o servidor de desenvolvimento
```bash
npm run dev
```
O servidor iniciará em `http://localhost:5173`.

### 3. Gerar a build de produção otimizada
```bash
npm run build
```

### 4. Testar a build de produção localmente
```bash
npm run preview
```
